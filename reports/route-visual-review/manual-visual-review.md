# 全量路线视觉与数据一致性审查报告

## 结论

本轮对仓库中的 **730 条有向路线记录**进行了全量映射，并对其对应的 **327 个唯一几何**逐个打开视觉卡检查。基于仓库内随包提供的楼层图，327/327 个几何均未发现可见穿墙、穿越科室/中庭、端点漂移、无意义往返或可明确安全删除的真实转弯。

本结论仅为 **`pass_on_packaged_map`**，不是患者发布授权。仓库缺少生成路线时使用的权威高清楼层图、现场步行复核记录、净空审批与哈希绑定的路线审批登记，因此 `releaseAuthorization` 统一保持 **`not_authorized`**。

## 低角度折线复核

低角度方向交替分布为：0次=230个, 1次=66个, 2次=27个, 3次=2个, 4次=2个。自动“微型锯齿”门禁只在交替次数 ≥5 时失败，因此“微型锯齿为 0”不等于“所有路线均没有低角度折线”。

其中 G0050、G0073、G0235、G0278 达到 3–4 次低角度方向交替，已单独放大复核；它们均沿扶梯、导医台、中庭或走廊边界渐进转向，不是左右摆动式锯齿。

## 代码与 CI 缺陷修复

1. **已修复：路线简化器非幂等。** 原实现按几何分组排序输出，第一次简化后会改变键顺序，第二次 `--check` 仍报告过期。新增回归测试后，输出按原记录顺序恢复，第二次运行保持字节稳定。
2. **已修复：审查工作流漏跑。** PR 更新现由 `pull_request` 默认事件覆盖，包括 `opened`、`synchronize` 与 `reopened`。
3. **已修复：CI 自提交与假绿风险。** 工作流改为 `contents: read`，不再在 PR 中自提交；路线与 Web bundle 必须已在分支中保持最新，否则只读检查直接失败。
4. **已清理：** 删除临时分支专用渲染工作流和一次性迁移脚本。
